# Machine Learning & Data Science with Python

A structured learning repository for B-Tech students covering ML/DS concepts using Python.

## Modules

| Folder | Topic |
|---|---|
| 01_intro_ml_ds | ML/DS Overview, Workflow, Terminology |
| 02_environment_setup | Anaconda, Conda Environments, Jupyter |
| 03_python_basics | Variables, Data Types, Lists, Dicts, Functions |
| 04_numpy_arrays | NumPy Arrays, Attributes, Indexing, Slicing |
| 05_numpy_operations | Element-wise Ops, Ufuncs, Aggregations, Broadcasting |
| 06_numpy_for_ds | CSV Loading, Filtering, Vectorization, Random Numbers |

## Requirements

- Python 3.9+
- Anaconda or Miniconda

## Environment Setup

```bash
conda create -n ml_ds_env python=3.9 numpy pandas matplotlib seaborn scikit-learn
conda activate ml_ds_env
jupyter lab
```
